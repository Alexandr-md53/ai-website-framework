# AI Website Framework

AI Website Framework is a modular framework for building AI-powered business websites.

Its purpose is to separate universal website functionality from business-specific logic, allowing new projects to be created quickly while sharing a common architecture.

The Framework is designed around reusable components rather than single-purpose applications.

## Vision

Traditional websites are usually developed independently.

AI Website Framework takes a different approach.

Each new website is created from the same Framework by combining:

- Framework Core
- Domain configuration
- Reusable components
- Business-specific content

The result is an independent website that can continue evolving without affecting other projects.

## Principles

- Framework first.
- Components before pages.
- Configuration before hardcoding.
- Reusability over duplication.
- AI is a native part of the architecture.
- Every feature should be reusable across multiple business domains.

## Goals

The Framework should make it possible to build websites for completely different businesses, including:

- Plant nurseries
- Cafes
- Hotels
- Medical clinics
- Law firms
- Online stores
- Educational projects

without redesigning the architecture for each project.

## Repository Structure

This repository contains the Framework itself.

Projects created with the Framework are independent applications and are not part of the Framework source code.

## Status

The Framework is currently under active development.

The first goal is to build a stable and reusable architecture.

After that, multiple business websites will be generated from the same Framework.
